# Portfolio

Reuben Alex's portfolio: a career shown as an agent trace. Each role, client engagement and
side project is a span on a timeline; select one to inspect it.

Built with Next.js, TypeScript, Tailwind CSS and Motion. Statically rendered.

## Editing content

All text, dates, figures and links live in `src/data/trace.ts`.

## Commands

```
npm run dev     # local development
npm test        # tests
npm run build   # production build
```
